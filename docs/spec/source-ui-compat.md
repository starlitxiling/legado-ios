# 书源管理界面对齐

基线：Android `2bdd3c58b`，轮次 5 U7。

列表包含搜索、分组关键字、校验状态、使用数、发现绿点、手动拖动和批量操作；导入预览区分新增、更新、相同，支持选择条目与记忆分组。二维码入口支持图片与系统扫描器，摄像头能力取决于设备。编辑页按原版顺序呈现七个分区、字段导航及可折叠设置，代码键盘提供原版 32 个键与 1–5 行配置。调试框聚焦时显示五种输入示例。

验证：SourceEditTests 13 项通过；模拟器 SourceInterfaceUITests 1 项通过，覆盖已有字段回填、列表多选、切换字段、辅助键输入和调试提示。原始结果：`.build/round5/u7-review.log`、`.build/round5/u7-ui-prefill.xcresult`。截图位于 `docs/5-UI对齐与解析补全/assets/u7-*.png`。摄像头扫码尚未在真机验证；Android 同屏人工视觉验收待完成。
