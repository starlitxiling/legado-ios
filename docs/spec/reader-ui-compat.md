# 阅读器对齐（轮次 5 U6，在途）

规格固定为 Kotlin `2bdd3c58b`。本页随 U6 分阶段更新，不代表 U6 整体验收完成。

## 已实现的配置层

- 九宫格支持 -1 至 13 全部动作值，沿用 clickActionTL 至 clickActionBR 原偏好键。缺失或非法值回落对应默认动作；九格没有菜单时恢复中央格为菜单。
- 六套预设直接取自固定版本 `defaultData/readConfig.json`，包内资源为 reader-presets.json。首套的字体、边距、页眉页脚槽位和颜色均以资源为准。
- ReaderSettings 使用完整 ReadBookConfig，保留标题字体 / 字重、字距、背景、页眉页脚与附加字段。字号范围 5–50，正文和页眉页脚上下边距 0–400、左右 0–100，行距 0–50，段距 0–20。
- ReaderStyleStore 从备份配置表读取全部样式，支持选择、修改、导入、导出、删除；最少保留五套。共用布局使用 shareReadConfig，颜色仍来自所选样式；默认共用配置沿用第六套。
- 样式编辑写入 readConfig.json / shareReadConfig.json 的备份记录；同步当前平面偏好供现有宿主使用。备份共用布局时更新共享排版，不覆盖每套独立样式的排版。
- 配置层 App 回归 294 项通过；四项 ReaderInterfaceConfigTests 覆盖所有动作、菜单保底、预设对拍、全部配置回读和样式持久化；另有共享备份回归用例。

## 排版与界面面板

- CoreText 接收文字色、字重、字体、字距、两端对齐、逐字换行及悬挂标点。正文行距严格使用 ChapterProvider 的配置值 / 10 行高倍数；标题行距为 1 + 偏移 / 100，偏移范围 -20 至 30。段距为字体高度乘配置值 / 10。CoreText 的零行高以 0.001 倍处理，避免零高框无法推进。
- 标点挤压按 PunctuationCompress 的开闭标点邻接与字形留白判定，最大减半；对左侧或两侧留白的压缩同步调整绘制位置。全量 / 相邻先排版，行末模式固定原行范围后压缩；标题不挤压。
- 底部对齐只扩展未到章节或图片边界的满页行间距；最后一页不拉伸。高亮与朗读范围使用相同行位置绘制。
- ChapterTitleParser 的章序拆分、序号字号/颜色/下间距已接入，并保存实际标题 UTF-16 长度供批注计算正文坐标。
- 界面半屏面板保留正文预览，提供四滑杆、五种动画、六套样式、共用布局；字体、字重、缩进、繁简转换、三组边距及联动、六个信息槽位、标题设置均连接排版。
- 长按样式可修改名称与日夜/墨水模式配色，导入背景图片、修改透明度、导入 JSON/ZIP、导出 ZIP、删除样式。图片保存为沙箱内相对文件名，ZIP 打包背景和导入字体。
- 信息槽使用 Kotlin ReadTipConfig 的实际编号，而不是选项显示序号：书名 7、标题 1、时间 2、电量图标 3、电量百分比 10、页码 4、进度 5、章序进度 11、页码与进度 6、时间电量 8/9。此处修正计划表及默认值文字描述与 Kotlin 资源不一致之处，原始预设保持不改。
- 支持 ReaderInfoTemplate 的已有模板字段，未知和嵌套占位符原样保留；用户重新选择槽位后清除该槽的自定义模板。页眉/页脚边距、字号、颜色与分隔线实时生效。

## 独立目录

- 全屏目录提供目录/书签标签，PDF 增加大纲标签。EPUB/MOBI 保留完整父子节点和无链接标题，TXT 分卷也可折叠；搜索显示命中节点及其父级，进入展开并定位当前章。
- 当前章强调色，缓存章使用深色文字；支持反转显示、展开/折叠、标题替换、可取消的加载字数。反转仅改变显示，不改章节索引、正文缓存键或阅读进度。
- PDF 大纲按物理页映射到章节，再跳到该章节内对应页图。书签支持添加、删除、跳转、搜索和 JSON/Markdown 导出，Markdown 段落顺序沿用 TocViewModel。
- TXT 可选择内置或自定义目录规则、编码和超长章拆分，重建后更新原书目录、清理旧缓存并保留书架身份。规则与 replacement 的持久化分隔符由 Core 统一生成。

## 反转、显式云进度与手动替换

- 反转按 Kotlin 码点与括号镜像处理，富文本保留标签、实体、换行及段首空白；带 MD5 的撤销标记可精确恢复原文，内容外部修改后不复用旧标记。
- 显式拉取允许选择云端较早进度，GET 读取不隐式上传；覆盖云端需要确认。测试全部使用 ReplayHttpClient，真实 WebDAV 凭据未用于写入。
- 模拟追读使用 Core 原有 Kotlin 日期算法，阻止跳入、翻入或预加载未解锁章节；禁用后恢复全部目录。
- EPUB 的 h1-h6 与 ruby 注音清理按位 2/4 控制，保留 ruby 主文字，切换清缓存后重新解析。Kotlin addDelTag 使用 AND 导致零值无法启用；iOS 此处采用 OR，修正该原版缺陷。
- 手动替换启用时按本书 ID 选择规则，忽略规则全局开关与适用范围，覆盖自动替换开关；空选择不替换。正文、标题、目录、预加载及全文搜索使用相同配置；全量规则变化可触发重新排版。
- 特殊样式设置同步到后续正文请求；反转本地书时先确认实际缓存存在。
- Core 712/0、AppCore 310/0；新增正文反转/手动替换/全文搜索联动专项 1/0。generic iOS 构建通过，模拟器手动替换与模拟追读菜单 1/0，截图 u6-reader-manual-replace.png、u6-reader-simulated.png。不进行 iPhone 测试。

## 高亮规则与书源重导入

- 高亮规则支持创建、编辑、启停、删除、排序和搜索。标题/正文独立选择，书名/书源范围按 Kotlin 的非空子串条件筛选；规则按顺序及 ID 处理。
- 匹配使用 UTF-16 范围，文字匹配不重叠，正则独立处理标题/正文区间；跳过无效正则和零长度结果，保留取消、超时及一万条匹配上限。
- 样式合并保留既有装饰，后续非空属性覆盖。字号、字距、字体、粗斜体先参与分页；背景形状、文字色、五类下划线、删除线、边框、逐字着重号和阴影连接 CoreText 绘制。高级 JSON 保留细节参数并校验格式。
- 重新导入本书书源从数据库当前 JSON 开始预览，可应用书源替换规则；确认后更新阅读器书源引用。定制按钮脚本收到当前章节实体。

## 正文图片样式与点击

- 默认、满宽、文字大小、独占一页使用实际图片尺寸参与 CoreText 排版；图片位置保留一个 UTF-16 空格，与正文位置及阅读进度一致。单图样式强制本书覆盖翻页。
- 本书设置覆盖书源默认；图片 URL 中 style、width、click 可单独覆盖，支持百分比宽度。文字大小图片通过 CTRunDelegate 占位，与文字共同分页；其它模式按可用页高等比缩放。
- 点击设置区分脚本、预览、不处理及双击；脚本绑定完整书籍/章节、src/result，兼容旧 js 属性。图片缓存提取保留原始 JSON 参数，正文显示复用书籍缓存。
