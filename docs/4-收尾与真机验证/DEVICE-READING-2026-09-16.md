- 启动：后台任务在应用启动回调中注册；数据库打开结果通过观察对象驱动启动页。
- JavaScript 内存：规则流水线、独立脚本与 URL 脚本入口设置释放池；结果转为原生值后释放上下文；成功、异常与初始化结束时清理异常引用。
