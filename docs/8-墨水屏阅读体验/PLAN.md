# 轮次 8：墨水屏阅读体验（分支 ios-eink）

目标：在 iPhone 上模拟真实墨水屏的阅读感受。起点 `257ef15cf`。用户要求覆盖全部方面，由主会话直接实现。
现状：墨水屏主题已有全局去色（ThemeEnvironmentModifier `.saturation(0)`）、纯黑文字、`pageAnimEInk` 默认无动画、阅读菜单无动画。缺系统转场与滚动惯性处理、毛玻璃/阴影、全刷闪屏、字体加深、纸张底色、图片抖动。

## 单元
| 单元 | 内容 | 验收 |
| --- | --- | --- |
| E1 全局静止 | 墨水屏模式下关闭 UIKit/SwiftUI 动画（导航进出、弹出页、开关、列表变化），列表滚动减速加快、去弹性 | 单元测试覆盖开关逻辑；UI 测试进出页面无动画仍可用 |
| E2 全刷闪屏 | 阅读器翻页时按设置每 N 页整屏「黑→白」闪一次（0 关闭，默认每 6 页），时长约 2 帧，可在面板手动触发「刷新屏幕」 | 计数逻辑单测；UI 测试翻页不受影响 |
| E3 纸面与文字 | 纸张底色（纯白 / 纸白 / 暖纸）、字体加深三档（CoreText 描边增粗）、可选关闭文字抗锯齿（锐利）、页眉页脚纯黑 | 渲染位图单测（加深后黑像素增多） |
| E4 界面去干扰 | 墨水屏下毛玻璃改纯色加细黑边、去阴影、阅读时默认隐藏状态栏、Tab 栏与导航栏不透明 | 构建与截图抽查 |
| E5 图片处理 | 封面、插图、漫画按设置做灰阶量化（16 级）或黑白抖动（Floyd–Steinberg）/阈值二值化，对齐 Android 漫画墨水屏模式 | 处理函数单测（输出仅含指定灰阶） |

## 约束
- 只在墨水屏模式（ThemePalette.isEInk）下生效，普通主题行为不变。
- 新设置项存入现有偏好（AppPreferences），备份可往返；不新增依赖。
- 每单元单独 commit 并推送 ios-eink；最后跑完整回归、真机安装经 SideStore。
