# 需求：将 Legado 适配到 iOS

## 原始需求

> 帮我做一个将这个 app 适配到 iOS 上的计划。

## 背景

- 本仓库（`starlitxiling/legado-ios`）当前内容是 Legado 的 Android 版（Kotlin，约 19 万行），目录名与远端仓库名虽带 `ios`，但尚无任何 iOS 代码。
- 上游 `gedoor/legado` 已于 2026-05-27 清空代码只留侵权公告，Issues / Discussions / Wiki 全部关闭；配套服务端 `hectorqin/reader` 同样只剩 `deleted`。本仓库是目前仍在持续开发的分支（近期提交含 #1302、#1306、#1310、#1311）。
- Legado 的核心价值在于「书源规则引擎」：用户导入社区书源（JSON），引擎按 CSS / XPath / JSONPath / 正则 / 内嵌 JS 规则抓取并解析网络内容。iOS 适配必须兼容这套规则格式，否则等于另做一个阅读器。

## 目标

给出一份可执行的 iOS 适配计划：技术路线选型、范围切分、阶段划分、风险清单，以及需要人类拍板的事项。本轮只产出计划，不写代码。

## 约束

- 计划中的仓库事实与外部技术断言必须有来源（仓库 `file:line` 或实际打开过的 URL），取不到的标「未核实」。
- 「只有人知道」的参数（团队技能、分发目标、范围取舍、仓库形态）列为待确认项，不猜。
