# 需求：阶段 4 功能对齐 Android

## 背景

阶段 3 交付的是 MVP：网络文字书源 + 书架 + 阅读主链路。人类要求「先都做了」——把 Android 端的其余功能（显示、书源导入解析的外围、登录、WebView、纯 JS 书源、听书、本地书、RSS、漫画 / 音频源、书源编辑与校验、备份上传、Web 服务等）逐项实现，暂不做真机测试。

## 目标

对照 Android 端 `io.legado.app` 的功能面，逐项实现或明确标注「iOS 不可实现 / 有意不做」。每个功能域一个单元，完成判据是：Kotlin 对应逻辑逐分支对齐并有离线测试；界面在模拟器可编译、可启动；`xcodebuild build` 与 `tools/build-ipa.sh` 持续通过。

## 约束

- 沿用双通道工作模式、PROGRESS 断点续传、每单元 commit。
- WebDAV 测试账号只读：备份上传功能可以实现，但任何测试与冒烟不得对真实服务器发 PUT / MKCOL / DELETE。
- 不联网的测试；真实站点冒烟只由主会话按需执行。
- 主会话代跑 `xcodebuild`；每批单元合并后至少跑一次 iOS 构建。
